# En Train Alain — V12.1

Prototype SNCF réel.

## Cette version
- conserve l'interface actuelle des allers et retours ;
- conserve la liberté de choisir séparément les horaires aller et retour ;
- transforme les arrêts ferroviaires intermédiaires en destinations plus pertinentes lorsqu'une destination structurante proche est identifiée ;
- évite notamment de proposer Longueau comme destination lorsque le train poursuit jusqu'à Amiens ;
- conserve les gares réellement distinctes comme Lille Flandres, Lille Europe, Lyon Perrache ou Lyon Part-Dieu ;
- conserve les informations de gare dans les données de trajet ;
- ne branche pas encore les prix temps réel.

## Données
Ne pas supprimer le dossier `data/` déjà présent dans le dépôt GitHub. Cette version ne contient volontairement pas les fichiers de données volumineux.
